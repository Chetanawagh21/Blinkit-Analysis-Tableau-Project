# Blinkit Sales Analysis – Tableau Project

## Project Overview
This project focuses on analyzing Blinkit sales data and presenting business insights through Tableau visualizations.

## Tools Used
- Tableau
- Data Visualization
- Sales Analysis
- Dashboard Reporting

## Project Objectives
- Analyze total sales and average ratings.
- Explore sales by item type and fat content.
- Compare outlet sizes and outlet locations.
- Analyze outlet establishment trends.
- Present key performance indicators through visualizations.

## Project Files
- `Tableau project.twb` – Tableau workbook containing worksheets and visualizations.
- `Blinkit.xlsx` – Source dataset, if permitted to share.

## Skills Demonstrated
Tableau |Data Visualization | Data Analysis | Dashboard Development | Business Insights

## How to Use
Download the Tableau workbook and its required source dataset. Open the workbook in Tableau and reconnect the data source if prompted.
